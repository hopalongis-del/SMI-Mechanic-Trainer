# SMI Mechanic Trainer

Standalone shop trainer. Not part of MaintainSMIP.

The game gives a real fleet cart and a complaint. The trainee types every step. The app grades the work against a rubric.

## Run

Double-click `Launch-SMI-Mechanic-Trainer.bat`

Opens http://127.0.0.1:8060/

## Add cases later

Edit `cases.json` and add another object to `cases`. Restart the app.
